# LavExpress
Sistema en Kotlin para la gestion de una lavanderia automatica.

## Estructura

- modelo/    tipos de maquina, estados del slot, ticket
- errores/   excepciones propias del sistema
- servicio/  validaciones, calculo de tarifas y operaciones del turno
- reporte/   salida por pantalla
- Main.kt    ejecuta un turno completo con los datos de prueba
